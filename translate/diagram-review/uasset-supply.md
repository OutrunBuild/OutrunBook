# uasset-supply review (round 1)

Reviewed against `outstake/uasset.md` + `outstake/README.md`. Renders inspected: 820px and 1100px PNG (`/tmp/diagram-png/uasset-supply-820.png`, `-1100.png`) plus SVG source geometry (`assets/diagrams/uasset-supply.svg`, viewBox 940x720). Known global issues (chip white-on-white, gray-text dimness, dark-grid style) excluded.

## P1

- [图形错误/箭头形状] Three flow endpoints coincide at one coordinate (474,271) on uAsset's top-left corner: paths `M 371 271 L 474 271` (PSM swap out, right-pointing green head), `M 371 157 L 371 104 L 474 104 L 474 271` (Genesis top-channel, down-pointing green head) and `M 371 385 L 371 440 L 474 440 L 474 271` (Leveraged Genesis bottom-channel, up-pointing white head) all stack there — renders as a merged triple-head blob (green+green+white) visible in both PNGs; the two channel segments also run flush along node borders (x=474 hugs uAsset's left edge, x=371 hugs the Genesis/Polend right edges). → Channel routes must terminate on the target node's top/bottom edge midpoints (e.g. x≈505, y=boxTop/boxBottom), not the left-edge corner; keep channels clear of node strokes. Layer: export script (channel routing).
- [图形错误] Both "fine-detail" texts are exported with CSS `opacity: 0` — `text.t-external[data-detail="fine"]` and `text.t-database[data-detail="fine"]` — killing the uAsset tag "Pegged stablecoin" and the Yield assets tag "wstETH · sUSDS · sUSDe…". Verified via getComputedStyle on the shipped SVG: both report `opacity: 0`. Any viewer that inlines the SVG (the file ships `tabindex`/`role="button"` for interactivity, so inline embedding is intended) loses both, including uAsset's defining "Pegged stablecoin" descriptor. Distinct mechanism from the known chip white-on-white bug. → Never emit opacity:0 on content text in the static export. Layer: export script.
- [产品语义错误] Edge `reserve → polend` labeled "Pay interest" is a wrong fact on every end. Per `memeverse/polend.md`: the leveraged user pays interest in uAsset (or offsets with GenesisCredit), it flows into the protocol treasury, and the debt quota is minted as uAsset — reserve assets neither pay nor carry interest into POLend, and no reserve flow into POLend exists (the quota is minted, not borrowed from reserves). → Delete this edge, or redraw the true mechanic (e.g. `uasset → polend` "Interest paid in uAsset · buys shares"); layer: src JSON.
- [排列布局] The "Mint at face value" chip floats 34–45 units above the green channel segment it labels (rect y 59–75 vs segment y=104) and lands at stage-header height, fused inline with "02 / Supply paths" (header baseline y=68) and crossing both stage-lane borders (lane 1 ends x=399, lane 2 starts x=446; chip spans x 372.4–472.6). Reads as a button attached to the stage title, detached from its flow. → Drop `labelDy: -24` (src JSON) and clamp labels to ride their segment, never entering the lane-header band y<90; layer: src JSON + export script.
- [排列布局] Bottom third of the canvas is dead: all four stage lanes are uniformly 600 units tall (y 46–646) while the lowest content ends at y≈457 — ~190 units (~32% of lane height) of empty grid above the legend. At the fixed 820px embed this shrinks every element ~30% vs a tight canvas, compounding the font problem. → Size lanes to content (or reflow so rows fill stages); layer: export script.
- [字体] At the 820px embed width (viewBox 940 → ×0.872) text is below legibility: node sublabels 7u→6.1px, auto-shrunk to 6.1u→5.3px ("Mint at par · opens position") and 6.4u→5.6px ("Genesis · leverage · settle"); flow chips 8u→7.0px; stage headers 9u→7.8px; even node titles only 10u→8.7px. The exporter auto-shrinks long sublabels to fit instead of wrapping/widening. → Raise base sizes and wrap sublabels to two lines with wider nodes (drop the per-node shrink to 6.1/6.4); layer: export script (+ shorter sublabels in src JSON).

## P2

- [颜色搭配] "Pegged stablecoin" fill is `rgb(167,139,250)` (light violet) on the light-violet uAsset node fill — barely readable even where not hidden by the opacity bug (see crop of both renders). → Darken the database fine-detail fill or give it a node-surface-appropriate color; layer: export script.
- [产品语义错误] Genesis Staking sublabel "Mint at par · opens position" uses "par" for the mint path; the chapters reserve "face value" for Genesis minting and "par" for PSM swaps (README: Genesis "minted at face value", PSM "Two-way 1:1 par swaps"; uasset.md: "accounted for at face value… swaps go both directions at par"). Collides with the PSM sublabel "1:1 at par" one row below. → "Mint at face value · opens position"; layer: src JSON.
- [产品语义错误] The third co-equal supply path (Leveraged Genesis → "Mint quota as uAsset") is styled as a thin gray "data flow" while the other two mint paths (Genesis mint, PSM swap-out) are thick green "primary data" — visually demotes one of the three paths the title announces. → Set `variant: "emphasis"` on the polend→uasset flow; layer: src JSON.
- [产品语义错误] Reserve assets sublabel "USDC · ETH · BNB" is a closed list omitting USDT, which uasset.md names among PSM reserves ("USDC, USDT, ETH, and BNB"); the SY tag uses an ellipsis for its open set, this one does not. → "USDC · USDT · ETH · BNB" or append "…"; layer: src JSON.
- [产品语义错误] PSM's defining two-way trait is invisible: README leads with "Two-way 1:1 par swaps", and the mint-cap release story ("Redeeming or swapping back burns and releases room") has no return leg — only reserve→PSM→uAsset minting is drawn. → Add a thin return leg uAsset→PSM ("Swap back · burns") or fold "two-way" into the sublabel; layer: src JSON.
- [产品语义错误] README's two-way supply-demand interlock ("OutStake mints it; Memeverse consumes it. The two sides interlock") has no demand-side trace: only the one-way supply arrow uAsset→Memeverse appears. Correctly no yield-backflow arrow, but the interlock itself is not conveyed. → Note the demand side on the Memeverse node/sublabel ("consumes uAsset — demand side") rather than drawing a return arrow; layer: src JSON.
