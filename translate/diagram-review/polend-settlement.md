# polend-settlement review (round 1)

Reviewed at 820px and 1100px renders against `memeverse/polend.md` + `memeverse/lifecycle.md` (+ `pol-splitter.md`, `four-pools.md` for cross-checks). Known global issues (white label chips / c-mask, gray-text dimness) excluded.

## P1

- [产品语义] Dead-end on the reserve path: "Draw reserve" has exactly one outgoing edge — "Shortfall exceeds reserve" → "Revert whole transaction". The covered case (shortfall ≤ reserve balance → transaction completes → protection window opens, per polend.md step 3) is not drawn, so the diagram asserts that drawing the reserve always ends in revert. → src JSON: add edge `reserve → protect` (or into a small "Settlement completes" join in the unlock lane) labeled "Reserve covers it → settlement completes", solid, contrasting with the dashed revert edge.
- [产品语义] Unsupported mechanism claim: node "Repay leveraged debt" sublabel "Recovered uAsset repays and is burned" and card item "repaid uAsset is burned". No chapter states the repaid leveraged debt is burned (checked polend.md, lifecycle.md, pol-splitter.md, four-pools.md; only GenesisCredit interest and POL-denominated fees are documented as burned). → src JSON: drop "and is burned" from the sublabel and the card item, or get the fact confirmed against the protocol spec first.
- [排列布局/orphan label] Edge label "Shortfall exceeds reserve" (SVG text at x=224, y=407) sits ~90px left and ~40px below its actual edge (reserve→rollback runs (284,367)→(344,367)); it lands straddling the lane frame's bottom border (y≈398–404) directly under the "Draw reserve" node, where it reads as a caption of "Draw reserve" or of the retry line, not as the revert condition. → src JSON: remove `labelDx: -90` / reposition near the edge midpoint above the line; or export script: clamp edge labels to a radius around the edge midpoint and off lane borders.
- [字体] Node sublabels are auto-shrunk to six different sizes: 6, 6, 6, 6.3, 6.4, 6.9, 7.7, 8 (px in a 720-wide viewBox). At the 820px embed width the 6–6.4px ones render at ~6.8–7.3px — effectively unreadable — and sizes clash inside a single row (row 2: cut 8 / liquidate 6 / repay 6.3 / residual 6). → export script: enforce a minimum sublabel size (~7.5px viewBox units) and one shared size per row; src JSON: shorten the offending sublabels ("Capped rounding-level shortfall" → "Rounding-level only") or widen those nodes.
