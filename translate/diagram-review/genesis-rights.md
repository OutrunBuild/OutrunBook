# genesis-rights review (round 1)

Reviewed at 820px and 1100px (2x PNGs). SVG: `assets/diagrams/genesis-rights.svg` (viewBox 1080x640, page scale at 820 = 0.759). Semantics checked line-by-line against `memeverse/genesis.md` (plus `memeverse/lifecycle.md` for the 365-day lock and YT/LP claim timing — both check out).

## P1

- [图形错误] 6 of 8 flow-label chips are blank white pills: chip text uses `class="t-muted"` (`fill:#ffffff`) on a `class="c-mask"` chip (`fill:#ffffff`) — white on white. Enumerated in SVG: `in-unlock, unlock-lp, unlock-static, lp-anchor, anchor-static, static-resume -> t-muted`; only the two `emphasis` flows (`in-yt`, `in-fees -> t-backend`) show text. So "Lock-up ends (365 days · fixed)", "One-time claim", "Opens protection window", "Sum of three parts", "Redeemed at static reserves", "Auto-resumes at expiry" are all invisible in both `genesis-rights.svg` and `genesis-rights.html`. → root cause is `renderers/dataflow/render-dataflow.mjs` (~line 413: `class="${variantAccent(flow.variant)}"` picks `t-muted` for default-variant labels; variantAccent must not be used as chip text color, or c-mask must be dark). Layer: export script (archify renderer).
- [字体] Sublabel font is 7 viewBox units → 5.3 CSS px at the 820px docs page width (node titles 10u→7.6px, stage labels 9u→6.8px, chip labels 8u→6.1px). Sublabels like "Auxiliary-pool LP + residual POL/PT" and the critical "30% + 30% + 40% = 100%" are unreadable at embed width. → raise `nodeTextFit.sublabelPreferred`/stage/chip sizes in `renderers/dataflow/render-dataflow.mjs` (or scale typography up relative to viewBox). Layer: export script.
- [排列布局] Node sigil collides with the centered title on 6 of 8 nodes — the `<>` glyph sits on the first letter: "ɑStandard Genesis input", "ɑuxiliary-pool fee share", "ɑTransaction that enters Unlocked", "ɑConservation anchor", "ɑSettled at static reserves", "ɑPublic trading resumes" (visible in all crops). Cause: sigil at `x+6,y+6` overlaps the centered title band (`baseline y+21`) whenever the fitted title still reaches the left 20 units — `brandLabelFitWidth` doesn't reserve the sigil zone. → shift title start right of the sigil or move the sigil to its own row. Layer: export script.
- [颜色搭配] White `t-primary`/`t-muted` text on the light sage backend-node fill (sampled rgb(155,184,177)) = contrast 2.12:1 — hard fail for body text, worst for the 7u sublabels ("Four pools pause public trading", "Exit risk on user after window"). → darken node fill or switch node text to a dark ink; keep white only on `c-external` (that node reads fine). Layer: export script (theme).

## P2

- [颜色搭配] The two chips that DO render use `t-backend` #34d399 text on the white chip = 1.92:1 ("Genesis succeeds; pro rata", "From Locked"). Same fix as the P1 chip defect: dark ink on white chips. Layer: export script.
- [箭头形状] Top-right chip pile-up: `unlock-lp` chip rect ends at x=689.3 and `lp-anchor` chip starts at x=694.9 — a 5.6-unit gap, they read as one merged pill; both straddle the stage-4 lane border; and "Sum of three parts" floats at the top corridor while its actual route is the lp→anchor vertical at x≈745, so it attaches to the wrong line. Also "Genesis succeeds; pro rata" (y=200) floats 43 units below its horizontal route (y=157). → set explicit `labelAt` for `lp-anchor` in src JSON; renderer should nudge overlapping chips apart. Layers: src JSON + export script.
- [排列布局] Dead band: last node row ends at svg y≈390 but lanes run to y≈563 and the legend sits at y≈575 — ~170 units (≈27% of the 640 height) of empty grid before the legend. → compact rows/viewBox height to ~470. Layer: src JSON (stage/row layout) or export script (viewBox fit).
- [箭头形状] The `in-unlock` route's vertical segment at x=400 passes 7 units from the right edge of the "Auxiliary-pool fee share" box (x=393) — at embed size it reads as touching the node corner. → move the via x to ≥420 in src JSON. Layer: src JSON.
- [产品语义] `lp→anchor` edge label "Sum of three parts" implies the one-time claim produces the conservation anchor. Per genesis.md the anchor is the pool-side coverage identity — "~30% auxiliary pools + ~30% PT backing + ~40% POL backing = 100%" of the standard-side commitment — a property of the four-pool structure at settlement, not the sum of the claim. → reword (e.g., "Covers principal jointly") or hang the anchor off `unlock-tx`/`static` instead of `lp`. Layer: src JSON.
- [产品语义] `unlock-tx→lp` edge label "One-time claim" duplicates the target node's title verbatim — the chip spends the reader's eye and says nothing new (the timing fact "after Unlocked" is the useful content, and "one-time" is already the node title). → reword the flow label. Layer: src JSON.
- [颜色搭配] Legend split "primary data" (green) vs "Rights & flow" (grey) doesn't track a real semantic difference: the two green flows (YT, fee share becoming claimable) are exactly as much "rights" as the grey `unlock-lp` flow. → rename entries to what the green/grey actually encode (e.g. green = "Genesis distribution", grey = "Lifecycle"), in src JSON legend entries. Layer: src JSON.
