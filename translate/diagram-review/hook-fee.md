# hook-fee review (round 1)

Rendered at 820px (2x + true 1x DPR) and 1100px. Source: `assets/diagrams/src/hook-fee.workflow.json`; SVG is what `memeverse/hook.md` embeds (line 18). Zoom crops: `/tmp/diagram-png/crop-*.png`, `crop-1x-lane1.png`, `crop-1x-lane3.png`.

## P1

- [颜色搭配] Tag texts are near-invisible: "Fixed in contract", "Cap 100% · fixed", "First trade not exempt" are emerald `#34d399` (`.t-backend`) on the light sage node fill (measured rgb(155,184,177), produced by white `c-mask` rect under rgba(6,78,59,0.4)). Contrast = 1.11:1. At true 1x/820px "Cap 100% · fixed" — a semantic-truth number — is unreadable mush. → Darken `.t-backend` on light fills (e.g. #047857) or drop the white c-mask underlay for tags. Layer: export script.
- [图形错误] The `</>` sigil collides with the title on 7 of 8 nodes: overlaps the "B" of "Base fee 1%", the "+" of "+ adverse/volatility/short-term fee", the "=" of "= dynamic fee", grazes "Pool-opening fee", and is half-occluded behind "EWVWAP" (sigil at translate(381,339) spans y≈341–348; title cap top ≈346). Only "Actual fee" clears. Reads as a rendering accident. → Place sigil above the title row or inset it in the corner with clearance. Layer: export script.
- [图形错误] Edge-label pill "Exempt: base fee only" overlaps the EWVWAP node's top border: pill rect y=320–334 vs node rect y=333 (pill is also exactly node-width, so it reads as a glued-on header). Caused by `labelAt: [430, 330]` pushing the label to the bottom of the 277→333 gap. Visible at 1x 820: the node's top border disappears behind the pill. → Set `labelAt` to mid-gap, e.g. [430, 305]. Layer: src JSON.
- [字体] Sublabels are illegible at docs width and mutually inconsistent: "per pool; volatility-linked" and "50%→1%, defaults adjustable" at font-size 6.2 → 7.1px at 820px; siblings 6.5 / 7 / 7.3 / 8 for the identical role. 7px mono on a docs page is below legible; the size lottery looks broken. → Floor same-role sublabels at ~8 units (≈9px at 820) and use one size; shorten text or widen nodes to pay for it. Layer: src JSON + export script.
- [产品语义] The 15-minute decay window appears nowhere in the SVG: "Pool-opening fee / 50%→1%, defaults adjustable" omits hook.md's headline "decaying to 1% within 15 minutes" (the chapter's other windows, 3s and 15s, made it in). The fact exists only in HTML card 3, and all three cards are dropped from the SVG export (0 hits vs 3 in HTML) — so the figure embedded in hook.md never shows it. → Sublabel "50%→1% in 15 min; adjustable" (fits at current width if size is unified). Layer: src JSON.

## P2

- [颜色搭配] Node titles/sublabels are pure white on the light sage fill: contrast 2.12:1 (WCAG fail). Washed-out look confirmed at both widths. Titles stay readable only because they're 12–12.5px bold. → Use a dark ink (#0f172a-ish) for `.t-primary/.t-muted` on light node fills. Layer: export script.

Layer: src JSON + export script.
- [排列布局] Ragged rows: tag-bearing nodes are h=68 vs h=52 siblings, so title baselines offset by 8 units within one row — "Base fee 1%" sits visibly higher than "+ adverse fee"; "Actual fee" higher than "= dynamic fee"/"Pool-opening fee"; tops and bottoms both misaligned. → Align tops per row or unify heights. Layer: export script.
- [字体] Hierarchy inversions: the "Legend" header (font-size 12) is the largest text in the whole figure — bigger than every node title (10.6–11); lane headers (font-size 10) are smaller than the node titles they introduce. → Lane header ≥ node title; legend header ≤ node title. Layer: export script.
- [排列布局] Cramped titles: "EWVWAP exemption" and "Pool-opening fee" (16 chars × 10.6 × 0.6 ≈ 101.8 units) leave ~4 units (≈4.7px at 820) padding in the 110-wide nodes — the first/last letters nearly touch the borders (clear in crop-ewvap-pill). → width 120 or smaller font for these two.
