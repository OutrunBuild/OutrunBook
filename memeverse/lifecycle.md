# 启动生命周期

一个 Memecoin 从启动到流通，经历几个清晰阶段。每个阶段该做什么、谁能做什么，下面按顺序讲。

## 阶段一览

```
创世(Genesis) ──达标──► 锁定(Locked) ──到期──► 解锁(Unlocked)
       │
       └──未达标──► 退款(Refund)
```

## 1。 创世(Genesis)

发起人设定规则（选哪些链、初始定价、最低筹集额度），创世开启。

- 参与者存入 uAsset 参与**普通创世**（基础参与方式）。
- 看好的人可用 uAsset 或创世积分**加杠杆**，在普通创世基础上放大份额（付利息）。
- 也可通过**预购(Preorder)**提前锁定 Memecoin —— 预购是独立结算通道，可与普通/杠杆创世叠加。
- 系统持续累计资金，直到达标或截止。

这一步聚集共识：谁先参与、参与多少，决定 Memecoin 起步体量。

## 2。 锁定(Locked)—— 创世达标

筹集达到最低额度，创世成功，进入锁定阶段：

- 协议部署**四池流动性**，Memecoin 与 uAsset 配对，正式建交易市场。
- 流动性被锁定约 **365 天**，项目方无法抽走资金，杜绝 rug。
- Memecoin 可在受保护的市场交易（详见[动态费率 Hook](hook.md)）。

**锁定后，各类参与者可以领取和操作：**

| 谁 | 能做什么 |
|---|---|
| 普通创世者 | 领取初始 YT（收益权）、领取辅助池手续费分成 |
| 杠杆创世者 | 领取杠杆 YT |
| 任何人 | 用 uAsset + Memecoin 加池，铸造 POL 成为 LP，赚手续费 |
| LP | 领取已累积的 LP 手续费 |
| 预购者 | 按线性解锁，逐步领取 Memecoin |
| 执行者 | 触发手续费分发，获得主池 uAsset 费 0.25% 的执行奖励 |

## 3。 退款(Refund)—— 创世未达标

到截止时未达最低额度，创世失败：

- 普通创世者存入的 uAsset 原路退还。
- 杠杆创世付的利息一并退还（uAsset 利息退 uAsset，创世积分退积分）。
- 预购资金也全额退还。
- 没有人损失本金。

参与创世**没有筹资失败的风险** —— 达标才推进，不达标全额退。

## 4。 解锁(Unlocked)

锁定期满，进入解锁阶段，各类参与者退出与结算：

| 谁 | 能做什么 |
|---|---|
| POL 持有者 | 烧 POL 赎回主池流动性(Memecoin + uAsset) |
| 普通创世者 | 一次性领取辅助池 LP 份额 + 剩余分配 |
| PT 持有者（辅助池 LP） | 按 PT 赎回 uAsset（PT 主要在辅助池作 LP，非普通创世者本金凭证） |
| YT 持有者 | 按 YT 分得结算后的剩余收益(uAsset + Memecoin) |
| 杠杆参与者 | 按付息比例领取结算残值 |

解锁后有一段**保护窗口**（24 小时），优先保障上述有序退出，窗口结束后才完全恢复无限制公开交易。

此后 Memecoin 进入常态运行：交易产生手续费、质押者赚收益、DAO 治理运转。

## 举例：一个 Memecoin 的完整一生

> 某 Memecoin 的发起人在 3 条链同时启动创世，设定最低筹资 5 万 UUSD。
> - **创世期**：有用户用 2000 UUSD 普通创世，有用户用杠杆放大份额，社区预购踊跃。累计达 50 万 UUSD，达标。
> - **锁定**：四池建立，该 Memecoin 上线，LP 在主池加池赚手续费。普通创世者领到 YT 和辅助池费分成；杠杆创世者领到杠杆 YT。
> - **解锁**：锁定期满，普通创世者领辅助池 LP 份额 + 剩余分配（本金 uAsset 守恒，与 Memecoin 涨跌无关）；PT/YT 持有者按规则结算；该 Memecoin 进入自由交易，质押者开始赚手续费，DAO 启动治理。
> - 若创世**只筹到 3 万（未达标）**：全员退款，普通创世者的 2000 UUSD、杠杆者的利息、预购资金全部原路退回，无人受损。

整个生命周期由协议自动编排，规则透明、阶段不可跳过，从源头规避了传统 Memecoin 的 rug 与抢跑问题。
