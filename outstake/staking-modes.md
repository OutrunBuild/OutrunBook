# 双质押模式：锁仓与包装

把生息资产铸成 uAsset，有两条路径。核心区别在于**增值收益归谁、流动性怎么给**。

## 锁仓质押（Lock）

把生息资产锁定一段时间（锁定期天数由你自选），创建一个属于你的**独立仓位**。

- 存入后立即铸出 uAsset（按当前价值）。
- 所选锁定期内**本金不能取回**，但仍在持续生息。
- 你可随时把**增值部分提取成 uAsset**（详见 [提取增值](draw-uasset.md)）。
- 到期后，你可赎回本金。

> **锁定期与最低存入**：锁仓天数没有合约强制的下限或上限——选择 0 天等于不锁，开仓即可赎回，实际可选的锁仓档位以界面为准。此外，开锁仓仓位有**最低存入额**，由协议方按资产与部署环境设置（包装质押不受此限），当前门槛以界面显示为准。

> **关于可用性**：正常情况下，以上操作随时可用；系统临时暂停期间会短暂不可用，你的资金安全留存，恢复后操作自动恢复（详见 [常见问题](../reference/faq.md)）。

**赎回须知**：uAsset 不只是稳定币，也是你取回质押资产的**凭证**。到期赎回时，你需要**持有并归还与仓位累计铸造量等值（本金 + 已提取的增值）的 uAsset**，并在操作时确认扣取授权；若这部分 uAsset 已用于其他场景（如参与 Memeverse 创世、转让、跨链），赎回前需先重新取得。赎出时到手的代币取决于所投协议的适配器，各协议「可赎出成」的资产见[适配器矩阵](sy-adapters.md)。

**增值归你**：锁仓期间生息资产升值带来的收益，你随时能拿走。代价是本金暂时锁定。

## 包装质押（Wrap）

把生息资产投入一个**共享池**，不开独立仓位，也没有锁定期。

- 存入后立即铸出 uAsset。
- 铸出的 uAsset 可自由转让，任何人持有都一样——取回权益跟随 uAsset 本身，不必是当初的质押者。
- **取回由 keeper 统一执行**：从共享池取回底层资产的赎回，由协议运营的自动化角色 keeper 在链上完成，按**面值**兑付生息资产（SY）。

**增值归协议**：共享池里生息资产升值产生的收益，归 OutStake 协议自留的收益池（由协议定期收取）。代价是你放弃这部分增值，换取 uAsset 的即时流动性与可转让性 —— 适合把 uAsset 当稳定币来用、来流通。这与 Memeverse 的协议自留国库（杠杆利息）是不同的池。

**会不会挤兑？** 不会。共享池的设计保证：当前汇率下，池里的生息资产（SY）始终**覆盖**已铸出的 uAsset 面值 —— 协议收割时只取走**超过债务等值部分**的增值，留足偿付底。因此正常情况下，赎回始终能按面值足额兑付。

这个足额兑付依赖底层生息资产的正常运作：如果底层汇率在极端市场条件下长期、大幅回落，池中生息资产的价值会低于已铸出 uAsset 的面值，此时赎回**整笔暂不可执行**——不会按比例折价兑付，而是等池子重新足额覆盖后，再按面值继续执行；期间你持有的 uAsset 不受影响，仍可自由转让使用。例如：用户在汇率 1.0 时投入 100 SY 铸出 100 uAsset；若底层汇率跌至 0.8，池中 100 SY 只值 80，不足覆盖 100 的面值，此时赎回暂不可执行（而不是每枚兑回 0.8）；汇率恢复后，赎回继续按面值兑付。

## 对比

| | 锁仓质押 | 包装质押 |
|---|---|---|
| 独立仓位 | 有 | 无（共享池） |
| 锁定期 | 有 | 无 |
| 谁能赎回 | 仅仓位主人 | 由 keeper 统一执行，按面值兑付 |
| 增值收益归 | 用户 | 协议国库 |
| 适合 | 想锁仓吃增值 | 要即时流动性 / 把 uAsset 当稳定币用 |

## 怎么选

- 想长期持有底层资产、吃它的增值收益 → **锁仓质押**（到期前随时提收益，到期赎本金）。
- 只想要稳定币的流动性、不在乎底层增值 → **包装质押**（铸出 uAsset 直接用、转让或跨链）。
- 担心锁仓到期忘了赎？有 [keeper 代偿](keeper.md)——锁定超时达到一定时间后协议会代为赎回结算仓位。

## 举例

> 同样是 1000 USDC 的生息资产（如 aUSDC）：
> - **选锁仓质押的用户**：铸出约 1000 UUSD。锁定期内底层 Aave 收益持续累积，可随时把增值部分提取成 UUSD；锁定期满（例如自选 90 天）赎回本金。适合想吃底层增值的人。
> - **选包装质押的用户**：立刻拿到约 1000 UUSD，去别的 DeFi 用或转让给别人，无锁定期；代价是底层增值归协议自留。适合只想要稳定币流动性的人。
