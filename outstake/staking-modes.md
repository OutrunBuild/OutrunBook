# 双质押模式：锁仓与包装

把生息资产铸成 uAsset，有两条路径。核心区别在于**增值收益归谁、流动性怎么给**。

## 锁仓质押(Lock)

把生息资产锁定一段时间（锁定期天数由你自选），创建一个属于你的**独立仓位**。

- 存入后立即铸出 uAsset（按当前价值）。
- 锁定期内**本金不能取回**，但仍在持续生息。
- 你可随时把**增值部分提取成 uAsset**（详见 [提取增值](draw-uasset.md)）。
- 到期后，你可赎回本金。

**增值归你**：锁仓期间生息资产升值带来的收益，你随时能拿走。代价是本金暂时锁定。

## 包装质押(Wrap)

把生息资产投入一个**共享池**，不开独立仓位，也没有锁定期。

- 存入后立即铸出 uAsset，即时进出。
- 铸出的 uAsset 可自由转让。
- **任何人**持有 uAsset，都能从共享池赎回（不必是当初的质押者）。

**增值归协议**：共享池里生息资产升值产生的收益，归 OutStake 协议自留的收益池（由协议定期收取）。代价是你放弃这部分增值，换取 uAsset 的即时流动性与可转让性 —— 适合把 uAsset 当稳定币来用、来流通。这与 Memeverse 的协议自留国库（杠杆利息）是不同的池。

**会不会挤兑？** 不会。共享池的设计保证：池里的生息资产(SY)始终**覆盖**已铸出的 uAsset 债务 —— 协议收割(harvestWrapYield)时只取走**超过债务等值部分**的增值，留足偿付底。因此任何 uAsset 持有者赎回时，池子都有足够的 SY 兑付，不存在资不抵债的挤兑风险。

## 对比

| | 锁仓质押 | 包装质押 |
|---|---|---|
| 独立仓位 | 有 | 无（共享池） |
| 锁定期 | 有 | 无 |
| 谁能赎回 | 仅仓位主人 | 任何 uAsset 持有者 |
| 增值收益归 | 用户 | 协议国库 |
| 适合 | 想锁仓吃增值 | 要即时流动性 / 把 uAsset 当稳定币用 |

## 怎么选

- 想长期持有底层资产、吃它的增值收益 → **锁仓质押**（到期前随时提收益，到期赎本金）。
- 只想要稳定币的流动性、不在乎底层增值 → **包装质押**（铸出 uAsset 直接用、转让或跨链）。
- 担心锁仓到期忘了赎？有 [keeper 代偿](keeper.md)兜底，你不亏增值。

## 举例

> 同样是 1000 USDC 的生息资产（如 aUSDC）：
> - **选锁仓质押的用户**：铸出约 1000 UUSD。锁定期内底层 Aave 收益持续累积，可随时把增值部分提取成 UUSD；锁定期满（例如自选 90 天）赎回本金。适合想吃底层增值的人。
> - **选包装质押的用户**：立刻拿到约 1000 UUSD，去别的 DeFi 用或转让给别人，即时进出，无锁定期；代价是底层增值归协议自留。适合只想要稳定币流动性的人。
